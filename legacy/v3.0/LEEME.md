# Legado v3.0

Versión de partida del proyecto: un solo archivo HTML (`patologia_digital_ia_3d.html`), su código fuente en partes (`src/`) y los recorridos de prueba con Puppeteer (`test/`).

- El HTML se arma así: `cat src/p1_head.html src/p2_core.js src/p3_scene.js src/p4_stage345.js src/p5_ui.js src/p6_tail.html > patologia_digital_ia_3d.html`
- Los scripts de `test/` tienen rutas absolutas del entorno donde se escribieron; hay que adaptarlas.
- Esta carpeta se conserva como referencia mientras se migra el código a la estructura modular. No se modifica.
