# Cómo participar / How to contribute

## Español

Este proyecto es de código visible, con derechos reservados (ver el aviso en [README.md](README.md)). Por ahora **se reciben incidencias (issues), pero no solicitudes de cambio (pull requests)**. Las solicitudes de cambio se cerrarán sin revisión; no es una crítica al trabajo, solo que el contenido y el código los mantiene el autor.

Qué sirve como incidencia:

- **Error**: algo no funciona, falla en consola o se ve mal. Indica navegador, sistema, tamaño de ventana, idioma y los pasos para repetirlo.
- **Sugerencia de contenido**: una idea para un módulo, una pregunta del cuestionario o una referencia. Si propones una afirmación técnica, incluye la fuente (DOI cuando exista).
- **Corrección de traducción**: el texto en inglés es un borrador pendiente de revisión. Indica la clave o el texto, lo que dice ahora y lo que debería decir.

Reglas del proyecto que conviene tener presentes: todo el contenido es sintético y se marca como «simulado»; no se publican datos de pacientes ni imágenes reales; no se suben claves, datos personales ni notas internas.

## English

This project has visible source with all rights reserved (see the notice in [README.md](README.md)). For now **issues are welcome, pull requests are not**. Pull requests will be closed without review; this says nothing about the quality of the work, only that the author maintains the code and the content.

What works as an issue:

- **Bug**: something fails, logs a console error or looks wrong. Give browser, system, window size, language and the steps to repeat it.
- **Content suggestion**: an idea for a module, a quiz question or a reference. If you propose a technical claim, include the source (DOI when there is one).
- **Translation correction**: the English text is a draft pending review. Give the key or the text, what it says now and what it should say.

Project rules worth knowing: all content is synthetic and labeled "simulated"; no patient data or real images are published; no keys, personal data or internal notes are uploaded.
